# Data

The dataset is not committed. Download the Tappy Keystroke Data from PhysioNet:
https://physionet.org/content/tappy-keystroke/1.0.0/

Extract it so this folder contains:

```
data/
├── Tappy Data/       # per-user keystroke logs (.txt)
└── Archived users/   # per-user metadata, including the Parkinsons label (User_*.txt)
```

Then run the scripts from the repository root as described in the main README.
